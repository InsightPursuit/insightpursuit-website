# insightpursuit.com

Public website for Insight Pursuit. Static HTML, CSS and JS with no build step. Netlify publishes this repo's `main` branch to insightpursuit.com.

This repo was written by Claude (Anthropic) for Insight Pursuit, and it is kept separate from the core product code.

## Forms

Sign-ups and contact messages go through Netlify Forms. Form detection must stay turned on in Netlify (Project > Forms). Submissions show up under Forms in the Netlify dashboard. Forms: `waitlist` (home page), `business` (For companies), and `early-access` (About page).
